# 交流区重设计说明

原型：`prototype/index.html`（`?theme=dark|light`，`?at=bottom|<id>`）。样式只用 `frontend/style.css` 已有变量，新增 token 前缀 `--dl-`，类名前缀 `cx-`。

## 1. 版式

从上到下：玻璃页头（标题、`整理`、虚线禁用的 `作战室·后续`）→ 要点卡（可折叠）→ 发言流（顶部是“已整理的 N 条原始发言”折叠区，再往下是“新发言”分隔线，打开时默认停在这里）→ 发言框（引用条、点名、输入）。≥1024 时右侧常驻 288px 的“投递追踪”栏：成员 2×2、待回应（按 Leader 合并，排队最久的排在最前）、状态说明。

## 2. 投递徽章

一个徽章由两段组成：`[@名字 │ 图标 状态]` 加 `[私聊图标]`。点左段看说明，点右段直接打开私聊。尺寸：高 26px（≤760 或 coarse 指针时 32px），圆角 8px，字号 12px，两段之间 1px 分隔线。桌面靠 `::after` 把可点高度上下扩到 32px，行间距 8px，热区不会重叠。

| 状态 | 外观 | 图标 | 文案 | 文字色（浅 / 深） |
|---|---|---|---|---|
| queued | 透明底、**虚线**框 `--dl-q-line` | 时钟 | 排队中 | `--text-2` |
| queued ≥10 分钟 | 琥珀底 `rgba(176,122,38,.13)`、实线框 | 时钟带“!” | 排队 N 分钟 | `#8A5A12` / `#E3B56E` |
| delivered | 卡片底、**蓝色实线**框 `rgba(53,121,183,.45)` | 单勾 | 已送达 | `#2B6398` / `#8FBFEC` |
| replied | **青色填充** `color-mix(accent 13%, surface)` | 双勾 | 已回复 | `--accent-text` |
| none | 只显示名字，细框 | 无 | — | `--text-2` |
| archived | `--hover` 底 | 归档盒 | 仅归档 | `--text-2` |
| failed | 红底 `rgba(180,88,75,.10)` | 三角“!” | 失败 | `#9A4134` / `#EBA393` |

每种状态同时靠“框型、颜色、图标、文字”四个信号区分，色弱用户也能分清。排队超时不加动画，只换成琥珀色；窄屏顶部的“待回应”条图标也一起变成琥珀色。超时从发言时间算起，后端以后补 `queued_at` 就改用它。

**说明浮层**：桌面悬停 220ms 弹出，点击则固定住；≤760 改成底部单（带遮罩，按钮 44px 高）。浮层写明三件事：对方现在的状态（如“离线”“在跑任务”）、它是否已经看到（加粗）、已等多久；底部的主按钮是“打开 X 的私聊”。replied 额外给一个“跳到回复 #id”。按 Esc 关闭，焦点回到徽章。

## 3. 脉络

- 被回复的发言顶部显示引用块（`#id 作者 摘要`，左边一条 2px 竖线）。点击后滚到原发言居中，原发言闪烁 2.2s（`--accent-soft` 底加 2px 描边）。原发言已整理进要点卡时提示去展开原始发言。
- 一条发言的后代回复≥2 条时，下面出现“脉络 · N 条回复”按钮（带头像和作者），展开后是一棵缩进树：每层缩进 20px（手机 14px），用 L 形连线，左侧有一条 2px 青色脉络线。点树里的任意一行就跳到那条发言。发言流本身始终按时间排序，不因为回复关系重新排列。
- 发言框上方的引用条：`回复 #id 作者 摘要`，右边“✕”可取消。如果回复的对象是 Leader 且没被点名，引用条上会标“会通知 X”。

## 4. 私聊直达的落点

| 入口 | 落点 |
|---|---|
| `detail` 卡 | 发言者私聊里该发言 `created_at` 时刻的完整内容 |
| Crew 代发的“回复在私聊里” | 发言者私聊里对被回复发言的回复（`channel:<reply.id>:` 前缀） |
| queued 徽章 | 对方私聊底部的“待送达：交流区 #id”标记 |
| delivered / replied 徽章 | 对方私聊里注入的“交流区 #id”输入；replied 接着看它后面的回复 |
| failed / archived 徽章 | 那条私聊消息所在的位置，failed 的可在原处重发 |

## 5. 三个视口

- **1280**：左侧栏 + 浮起的主卡片 + 右侧投递追踪栏，要点卡默认展开。
- **758（≤760）**：去掉左侧栏，主卡片铺满，出现返回键；投递追踪收成页头下的“N 位 leader 待回应”条，点开是底部单；要点卡默认折叠；点名选择改为横向滚动，控件统一 32–44px。
- **375（≤620）**：页头分两行（返回 / 标题 / 整理；副标题 / 作战室），副标题改用短文案；脉络树铺满宽度并隐藏时间；徽章区里“点名”标签单独占一列，徽章在右侧换行。

## 6. 无障碍

徽章左段的 `aria-label` 写全句，例如“点名 语音：已排队 14 分钟，对方还没收到。点开看说明”，并带 `aria-haspopup="dialog"`，展开时加 `aria-expanded`；私聊按钮的标签是“打开 X 的私聊并定位到这条点名”。徽章文字对比度：浅色 4.96–6.37，深色 4.74–7.86，都达到 AA。“点名”标签沿用现有的 `--text-3`（约 3:1），只起提示作用，完整含义已经写在 aria 里。开启 `prefers-reduced-motion` 时，闪烁改成静态描边。

## 7. 和作战室怎么衔接

- 徽章已经包含作战室要用的 `archived` / `failed` 两态，作战室直接复用同一套徽章。
- 右侧投递追踪栏就是作战室右侧面板的前身；“成员”格子以后升级为顶部的参战栏，加上暂停 / 接管。
- 脉络树就是“升级为作战室”的天然单位：以后在脉络按钮或页头的 `作战室` 入口上，把这串讨论和里面的成员一起带进房间。
