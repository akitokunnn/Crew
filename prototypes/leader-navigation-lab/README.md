# 多 leader 导航原型：Leader 折叠列 + 工作集

双击 **`index.html`** 即可打开，不需要安装依赖或启动服务。页面完全离线，不连接正式 Crew，也不调用 AI。发送、拍板、验收和开始推进只改变当前页面里的示例状态，刷新后恢复初始数据。字体和 Crew 标识直接引用 `../../plugin/crew/web/`，请保持仓库中的相对位置。

这是供用户评价的选型原型，不是已经确认的定稿，也不代表正式产品已经决定这样改。

## 相对旧 B 改了什么

| 旧 B（36 项单 leader） | 这一版 |
| --- | --- |
| 第一项任务之前有十层品牌、标签、搜索和筛选 | 侧栏顶部只有项目、搜索、工作台三行，下面直接是 leader |
| 只有一张 leader 卡，其他组的待处理完全看不见 | 6 个 leader 各占一行，折叠时也显示琥珀色待处理数 |
| 36 项按状态分组，全部挤在侧栏里 | 侧栏只显示当前组的工作集：总会话、部分待你、当前项、少量最近项和“全部任务”；完整清单放在主区域 |
| 任务区和 leader 平级，看不出归属 | 工作集缩进挂在 leader 下面，并有一条引导线 |
| 当前项是浮起的白卡片，还带 › | 当前项改为浅底、加粗和左侧 2px 竖线 |
| 同一个任务有三种叫法 | 全部使用同一个任务标题，放不下时截断，悬停显示全名 |
| 放大镜图标也被用来表示“定位” | 只保留一个真正的搜索（Ctrl K） |
| 顶部和输入框下重复写任务名 | 顶栏只有一行：`leader / 任务 状态`；输入框占位写明消息发给谁 |

行首箭头只用来展开或收起，**不会切换对话**，可以借此看看其他组。点 leader 名称会切到这一组上次打开的对话。每个对话分别保存草稿、消息、滚动位置和决策方式。

## 五分钟试用

1. **换组与草稿**：在当前 MiPS 任务里写一段草稿，不要发送。点“音频前处理”，再点它下面的“总会话”，写另一段草稿。点回 MiPS，应回到原来的任务，两段草稿互不影响。
2. **看看别组但不切换**：点“实机回放与验收”行首的箭头，只展开它，当前对话不变。
3. **跨组待你**：点“工作台”。待处理按 leader 分组，点第 3 组 NPU 的任意一项，直接进入那个任务。
4. **完整清单**：点 MiPS 下的“全部任务 36”，搜索“静音”或切换状态范围，进入一项后点左上“全部任务”返回，搜索词和阅读位置都会保留。按 Esc 回到打开清单前的对话。
5. **待规划任务**：在清单中打开“句尾点头幅度标定”。打开、切走或修改决策方式都不会开始它；只有点“开始推进”或“发送并开始”才会开始。
6. **快速搜索**：按 Ctrl K（Mac 上用 ⌘K）输入“回放”，结果会标出所属 leader。Ctrl B 可以收起或展开侧栏。
7. **手机宽度**：在浏览器开发者工具中设为 390×844。☰ 会打开当前组那一层，点“‹ 全部 leader”回到所有 leader；在这一层点名称会直接切到该组，点右侧 › 只进入该组浏览。
8. **键盘**：在输入框里写草稿后按 Ctrl K 再按 Esc，焦点回到输入框，草稿和光标位置都在。资料、菜单、说明弹窗和手机导航关闭后，焦点回到打开它的那个按钮。浮层打开时 Tab / Shift Tab 只在最上层里循环，底下的页面不可操作。中文输入法组字时按 Esc 只取消组字，不会关闭清单或浮层。
9. **低频入口**：项目名下拉菜单里保留了交流区、Git、我的待办、会话库和用量的说明。它们在新导航里的位置还没有确定。全局助手在侧栏底部，会打开一个独立页面，可以返回项目。

## 文件

- `index.html`：入口，使用经典 `defer` 脚本，没有 ES 模块。
- `data.js`：固定示例数据，包含 6 个 leader 和 101 项任务。
- `state.js`：本原型自己的导航状态，包括 scope、各组上次对话、最近打开、展开集合、当前视图和清单检索状态。
- `seed.js`：根据示例数据生成各对话的初始内容。
- `app.js`：渲染与交互。
- `styles.css`：样式。

由 Claude Code（Opus 5.5，high）设计和施工，主控为 Codex。

Codex 复核时补齐了悬停/选中底色上的辅助文字与操作图标对比度；版式和交互沿用 CC 设计。当前示例在本机 Chrome 的桌面、短窗口和窄屏下走过跨组草稿、工作台待处理、清单检索返回及键盘焦点流程。原型不做刷新持久化，仍需用户看图和实际操作评价。
