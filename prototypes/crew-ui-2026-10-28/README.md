# Crew 可点击交互原型 v2

2026-10-28。这是一份待用户体验的设计方案，**不是正式 Crew 界面，也不表示布局已经拍板**。

## 打开

无需安装依赖，可以直接用浏览器打开同目录的 `index.html`。推荐独立本地预览：

```powershell
node prototypes/crew-ui-2026-10-28/serve.cjs
```

- 电脑：<http://127.0.0.1:4318/>
- 390px 手机交互预览：<http://127.0.0.1:4318/mobile.html>
- 端口占用时可在本次进程设置 `CREW_PROTOTYPE_PORT` 后启动。服务器仅绑定本机回环，不提供远程手机连接。

同目录包含全部 HTML、JS、CSS 和 Crew 标志，复制整个目录即可离线体验。手机页面是浏览器内的窄屏预览，并未验收真实手机或远程登录。

## 推荐的信息架构

采用任务导航与对话常驻、资料按需展开的结构。v2 根据“拥挤、信息密度高”的体验反馈，减少同时可见的区域：首页沿单一阅读轴呈现待处理摘要和工作区近况；具体任务在导航或进入工作区后查看。任务页只保留一处标题，“资料”内再切换详情、成员和成果；当前模式、整体停止、置顶在任务控制中，对话停止仍留在输入区。导航可以收起进入专注对话。

| 位置         | 内容与归属                                                                       |
| ------------ | -------------------------------------------------------------------------------- |
| 全局入口     | 首页、个人助手、TODO 与灵感                                                      |
| 工作区       | 普通项目文件夹；列出任务，关联工作区指向同一任务；工作区总对话独立保留           |
| 任务         | 唯一负责人 leader；默认进入其任务对话；任务详情、拍板、约定、成果与历史归属任务  |
| 成员         | 本人独立对话；顶部可沿任务、leader 返回；整体要求保留原话并模拟同步              |
| 任务内资料区 | 详情、成员、成果与文档，共用一个按需区域；报告可以进入宽幅阅读                   |
| 置顶任务     | 左侧靠上的跨工作区快捷入口，就地取消，不改变任务归属                             |
| 次级能力     | 更多中的公共频道、Git 跨工作区查看、用量与额度、会话库、历史、垃圾箱、后台与运维 |
| 设置         | AI 默认、可编辑提示词、原生权限、外观、通知、本机数据与原生来源                  |

资料只从任务内进入，没有恢复侧栏的项目资料或文档中心。个人助手是全局入口，工作区对话与具体任务对话互不猜送消息。

主要路径：**首页「声纹的两个取舍」→ 原任务对话 → 点击知衡或资料中的成员 → 成员对话 → 顶部林序返回 → 成果 → 报告／网页体验 → 返回原对话反馈**。

## 可以实际操作的内容

- 直接发起对话形成样例任务，编辑标题、目标、完成标准、主工作区与关联工作区。
- 切换任务与成员，保留独立草稿、阅读位置和资料展开状态；刷新后继续。
- 执行中立即插话，或明确排队，查看和发送／取消队列；附件只保留本地样例文件名。
- 对话按钮只停止当前 AI；任务按钮模拟停止本任务及成员。继续时不重新启动已交付成员，手动停止不被 TODO 完成或讨论消息覆盖。
- 任务级全自动模式，成员继承；原生权限独立放在设置中。
- 在原对话展开“讨论两个取舍”，暂存两项选择后统一拍板；首页摘要深链会直接展开该讨论。成员与成果默认显示简短事件，详细内容按需进入。
- 查看带版本号的成果、图示、表格与图表；报告阅读中模拟收到更新，保留旧稿与阅读位置；版本恢复只模拟向 leader 提出明确要求，保留未发送草稿。
- 「记下来」只保存原话到同一张清单，并模拟 QQ／Lark 通知；「开始聊」进入任务对话。TODO 可完成、补说明、按工作区筛选或回原任务。
- 通用、leader、成员、助手、报告、摘要、上下文交接七类提示词通过“工作规则”下拉选择，编辑器全宽显示；全局、工作区、单 AI 独立覆盖，显示来源与范围，可恢复继承、查看修改历史和当前 AI 的样例加载快照。保存供新会话使用，主动应用才更新选中 AI 的样例快照。
- 设置中的提示词草稿与选中位置保留。浅色、深色、字号与减少动态效果可体验，且尊重系统减少动态效果偏好。
- 体验指引中可打开手机预览或重置两份原型浏览器存储。

视觉沿用 Crew 的暖灰底色、灰绿强调色、低对比边界和原标志。任务切换约 180ms，资料展开约 250ms，新成果只做一次短强调；状态同时有文字说明。

## 样例边界

所有任务、人物、消息、版本、图表数字、文件路径、模型和通知均为明确样例。页面通过 CSP 禁止网络连接；没有调用 Crew、Claude Code、Codex、QQ 或 Lark，没有读取正式数据库、home 或原生配置，也不运行真实命令。用量保留未连接状态，不编造额度。

本机文件夹、下载文件、原生发现、接入会话、版本恢复、垃圾箱与运维展示入口和模拟反馈，不执行真实操作。手机成果体验是网页；PC 程序或文件夹的真实启动等待正式实现。

仅写入 `crew-design-prototype-v1` 和 `crew-design-settings-v1` 两个浏览器存储键。原型不是现有数据迁移或后台协议的实现方案。

## 导航逻辑修正

置顶是跨工作区的快捷入口：任务一旦置顶，就出现在左侧导航靠上的“置顶”区，可直接进入原任务，并就地取消置顶。任务仍属于原工作区，取消置顶不删除任务；刷新保留置顶状态。手机打开导航即可直达，就地取消后导航保持展开。更多页不再列出置顶卡片。

Git 在工作区页提供直接入口，进入时携带该工作区；Git 页切换工作区会同步路径与所展示的样例内容，顶部能回到对应工作区。全局进入时需要明确选择工作区，不再静默选中 Crew。全部为只读样例，不检查真实仓库，不初始化普通文件夹。

本轮验证：浏览器实际检查了置顶立即出现、刷新保留、直接进入原任务、在更多页就地取消且不跳页、置顶前后草稿不变、390px 下取消后导航保持展开；Git 从来源工作区进入并正确切换与返回。测试临时置顶已还原，保留用户原有置顶、任务模式、消息和草稿。
