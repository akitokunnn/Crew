# Crew 项目导航与对话原型

这个原型演示一个项目里同时有多个 leader，每组有几十项任务时，用户怎样找到当前对话、待处理事项，以及组员分工。人物、任务、分工和对话都是样例：6 个 leader、98 项任务。

用 Edge 或 Chrome 直接打开 [index.html](index.html)，不需要安装依赖，也不需要启动服务。页面打开后默认进入工作台。

## 布局：左边找地方，中间做事，右边看人

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| **leader 栏（60px）** | 项目菜单、工作台、快速切换、各 leader 头像和待你数，底部是全局助手和设置 | leader 全名、任务 |
| **对话列表（248px）** | 当前 leader 的全名和职责、总会话、全部待你的任务、在做的任务、打开过的组员对话、「全部任务 N」 | 状态筛选、搜索框、已结束和未开始的任务 |
| **中间** | 对话；或工作台、完整清单、全局助手页面 | 重复的标题和说明 |
| **右栏（320px）** | 和当前对话有关的人：在任务里显示本任务分工，在总会话里显示组员各在哪些任务 | 另一份任务清单 |

- **对话列表的规则是固定的。** 待你的任务全部列出。「在做」只列推进中的任务，加上这次打开过的任务。其余任务都在「全部任务」里。不靠算法挑「工作集」，用户能预测某项任务会不会出现在侧栏。
- **顶部只有一行：** `人员 / 总会话或任务名`、状态、载体，右侧是资料和右栏两个图标按钮。标题本身就是返回入口：在 leader 的任务对话里点 leader 名，回到总会话；在组员对话里点任务名，回到 leader 的任务主线。输入框的占位提示写明消息发给谁。
- **工作台是首页。** 第一段是「待你处理」，跨 leader 汇总，按 leader 分组，也包括总会话里的拍板，点击直达对应对话。第二段是「最近对话」，带草稿标记。第三段是「各组」，显示每组待你、推进中、未开始的数量。
- **完整清单在中间区打开。** 可以搜索任务名、编号或组员，按状态过滤并显示计数。按 Esc 或点「返回」回到打开前的对话。搜索词会保留。
- **快速切换：** 按 Ctrl K（Mac 上是 ⌘K）可以跨 leader 查找任务或总会话。不输入时列出待你事项。
- **窄屏：** 宽度 1180px 以下，右栏改为按需滑出。760px 以下，leader 栏和对话列表一起收进左侧抽屉。

## 保留的业务规则

- leader 是任务的主人。后端会给 leader 自动写入一条分工，界面把它当作主责；组员 = 全部分工 − leader。只有 leader 有总会话，待命组员没有对话入口。
- 每个对话（人员, 任务）分别保存草稿和阅读位置，跨 leader 切换也不会串。回到某个 leader 时，会回到这个 leader 上次打开的对话。
- 打开或切走一个未开始的任务都不会启动它。只有点「开始推进」或在任务对话里发消息才会开始，这和正式产品一致。暂停的任务只能查看。
- 交付与文档从任务标题栏右侧的资料按钮进入，不新增侧栏资料中心。全局助手是独立页面，入口在 leader 栏底部。音效设置沿用现有设置页。

## 借鉴了什么

以下依据对这些产品的了解，本轮没有重新查阅原文。

- **Slack、Discord 的工作区栏加频道列表：** 左侧一窄栏只放身份和提醒数，切换后旁边一栏只列这一组的对话。Discord 的服务器栏在任务很多时也只显示徽标，不展开内容。这里把 leader 当作「工作区」：几十项任务不会挤在同一条侧栏里，leader 长名称也只出现在对话列表的头部。
- **Discord 频道右侧的成员列表：** 成员列表跟着当前频道变化。这里的右栏也跟着当前对话变化：任务里看分工，总会话里看谁在做什么，不再和左侧重复列任务。
- **Linear 的 Inbox 和视图：** 需要你处理的事集中在一处，完整列表作为主区的页面打开，侧栏不堆分组和筛选控件。
- **VS Code、Notion 的面包屑：** 标题就是当前位置，点上一级可以返回，不需要另放「返回」按钮或「当前对话」下拉。
- **Linear、VS Code、Raycast 的 Ctrl K：** 一个快捷入口覆盖低频跳转，侧栏不常驻搜索框。

## 接入依据

`goals.get()` / `goal_api.card()` 返回 `assignments`，工作区快照的 `goals` 已经包含分工，任务详情提供 `executions`。`model.js` 负责投影：当前执行按 `goal_id`、`session_id`、本轮 `round` 和 `requirement_version` 匹配后，取最新 `generation`。`released` 的分工和已结束的任务算历史。工作台里「等了多久」和待你的问题，在样例中用 `updated` 和 `ask` 模拟，接入时需要核对现有快照里对应的字段。

- 从工作台直达别组任务
- 跨 leader 的草稿与返回
- 右栏随对话切换，以及标题返回
- 未开始与暂停
- 完整清单
- 快速切换
- 完整图谱
- 长名称与空组
