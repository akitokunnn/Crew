# Crew 桌面更新

0.1.2 在全局「工具与更新」页增加 Crew 卡片。先点「检查 Crew」，再点「更新 Crew」；卡片分别显示桌面、运行中的后台、Claude 插件登记版本和本次可用版本，「安装来源」可查看实际路径。

本次可用版本是**当前桌面自带版本**。此入口不会从互联网下载新的 Crew 桌面程序；取得新版桌面后，可用它统一后台、命令入口和插件。页面原有的自动更新开关只管理 Claude Code / Codex CLI，Crew 更新始终由用户手动发起。

更新时先关闭新任务入口，确认整个 Crew HOME 空闲，再用 SQLite backup API 保存数据库并检查备份完整性。任务或摘要仍在运行时等待，可取消；外部 Crew 成员仍存活时需先结束相应会话。更新过程同步已安装且来源已确认的 Claude Crew 插件、优雅停止自有后台、切换命令入口，并在原端口启动和验证新后台。已有工作区标签与草稿保留，备份路径显示在卡片中。

当前窗口借用其他窗口的后台、旧后台不支持更新准备、插件实际来源与桌面包不符时，卡片说明阻塞原因。先退出原 Crew，再打开当前版本，或按提示统一插件来源；不会终止未知后台或猜测安装目录。停止超时不会启动第二个后台；后续失败保留备份并显示真实失败原因，不自动回退旧版本。

已有 Claude 会话需重载插件或重开才能使用新的 hooks。新会话与成员启动仅初始化缺失命令入口，主动更新或显式安装才切换既有来源。

针对性验证：`cd desktop; node --test test/crew-updates.test.cjs`。真实隔离 Electron 验证：`node scripts/smoke-crew-updates.cjs`；插件状态使用声明过的测试夹具，真实执行更新锁、数据库备份、后台停止/重启及原端口和工作区保留，不启动模型。

本机交付验证（2026-10-25）：后端相关模块与新增更新用例共 344 项通过；主控独立复跑新增后端 17 项、桌面全部 66 项、真实隔离更新窗口流程和 0.1.2 便携版启动均通过。打包后的后端生产文件摘要和桌面 19 个源文件均与验收源码一致。正式数据库已备份，更新前后 SHA-256、记录数量和完整性一致；正式服务未启动。本机插件登记与 CLI 已统一到 0.1.2，桌面快捷方式指向新版便携包。
