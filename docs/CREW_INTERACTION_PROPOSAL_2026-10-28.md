# Crew 交互布局提案

2026-10-28 · Codex 与 Claude

首选任务侧栏与对话常驻、资料按需展开的布局，让用户在多个项目之间持续推进，并随时进入成员对话和成果。

依据 [产品需求草案](CREW_PRODUCT_REDESIGN_2026-10-28.md)。本轮 Claude 已完成只读评审，Codex 核对了现有布局、草稿恢复与文件读取入口。以下布局和动画是待体验的设计建议，产品实现尚未修改。

## 两种可体验布局

| 方案 | 呈现 | 适合情况 |
| --- | --- | --- |
| 任务工作台 首选 | 左侧按工作区列任务，中间为当前对话，右侧资料按需展开 | 多项目同时运行，经常来回切换 |
| 专注对话 | 导航默认收起，对话占据主区，通过任务入口和回溯切换 | 长时间讨论或阅读，希望内容更宽 |

两者共享任务和资料组织方式，可以用导航开合相互衔接。手机使用单栏进入任务、成员和文档。

## 导航与任务对话

全局入口包括首页、个人助手和工作区。公共频道、Git、用量与额度、待收编、历史和设置沿用现有能力，按信息层次安放。

工作区展开后主要列任务，每项显示标题、当前状态、一句进展，以及新成果版本提示。任务位于主工作区，关联工作区提供指向同一任务的入口。

任务主区是与 leader 的对话。顶部显示工作区和任务来历、状态、任务全自动开关、任务停止及资料入口。成员对话继续使用同一主区，顶部提供“任务 → leader → 成员”回溯。

输入框接收文字、图片和文件，提供立即发送与排队发送。停止当前回复位于对话操作中，与顶部停止整个任务分开。

任务切换保留各自草稿、阅读位置和展开状态。进入设置后返回，继续原位置。

## 一个按需资料区

任务详情、成员、成果共用一个资料区，按入口切换内容。宽屏可以推开对话，较窄窗口使用覆盖层或进入阅读页，手机单栏打开。

成员列表显示当前工作、状态和载体，点击本人进入对话。工作区的架构总览入口保留，用户可以继续查看并点击原有关系节点。

复杂报告可以扩大到主区阅读，返回时回到之前的对话对象和阅读位置。报告、成员和任务详情都明确标出当前所属任务。

## 首页与拍板

首页呈现待用户处理的短摘要、按工作区组织的进展和快速输入。待拍板只跳转原任务，完整说明与讨论保留在对话中。

拍板事项在对话里沟通清楚，可以暂存多个选择后一起提交，也可以直接用自然语言逐项回答。打开一个问题不应丢失其他问题的临时选择。

## 动画与反馈

动画延续现有主题和流光视觉，表达位置与状态变化。以下数值为设计起点，需通过实际体验调整。

| 变化 | 反馈建议 |
| --- | --- |
| 同级切换任务 | 约 120 至 180 毫秒的内容交接，保留导航位置 |
| 进入成员或返回 | 约 180 至 240 毫秒的轻位移，来历同步变化 |
| 展开资料 | 约 220 至 280 毫秒的面板移动，对话宽度平滑调整 |
| 新阶段成果 | 一次短流光或强调，随后保留明确版本徽标 |
| 报告阅读中更新 | 保留当前位置，显示可进入新内容的提示 |
| 正在运行与等待用户 | 状态文字与标记清楚区分；进度数值需要实际依据 |

尊重系统减少动态效果设置。动画不改变任务、拍板或消息实际生效的时间。

## Codex 对评审建议的收拢

采纳 Claude 的任务侧栏、按需资料区、三段成员回溯、阅读后返回对话，以及复用现有流光和状态保存机制的建议。

手机继续保留用户已经确认的任务模式切换和设置操作能力。评审中提出的 PC 专属授权限制不进入本提案，手机的轻量化体现在界面组织。

旧 leader 总会话和已有目标需要单独制定迁移映射。提案的迁移默认建议是保留旧目标对应的任务及原始聊天，旧总会话作为工作区历史可访问；迁移不自动启动原本停止的执行。

全局首页要支持网页访问，远程文档读取要接入已认证的资料访问链路。这些是后台方案需要解决的事项。

## 源码核对依据

- [页面骨架](../plugin/crew/web/index.html) 与 [布局样式](../plugin/crew/web/style.css)：现有侧栏、主区、关系栏与宽屏切换。
- [对话与导航](../plugin/crew/web/app.js)：现有成员直聊、返回 leader、资料入口和架构总览。
- [草稿与阅读位置](../plugin/crew/web/chat.js)：按工作区、会话和目标保存草稿，卸载前保存滚动位置。
- [文件读取](../plugin/crew/web.py)：现有本机 Host 限制，远程资料读取需要明确衔接。
- [桌面首页](../desktop/src/home.html)：当前桌面首页为本地入口，网页首页需要复用或提供对应数据链路。

只读评审原始结果保存在项目忽略的临时任务目录中；本提案保留经主控核对和收拢后的结论。
