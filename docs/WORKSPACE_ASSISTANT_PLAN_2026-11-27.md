## 接口约定（前后端分头施工以此为准）

- `assistant.open` / `assistant.state`：新增可选参数 `project`。缺省 → 系统管理员（现状）；给出 → 该工作区助手，返回结构同现有，另加 `kind: 'workspace_assistant'`、`project`，overview 固定本区。系统管理员返回 `kind: 'assistant'`（不变）。
- `notes.list`：人调用必须带 `project`；另接受 `unassigned=1` 只返回 project NULL 的旧想法（只读 + 可归属）。返回的 tags 为本区标签。
- `note.capture`：必须带 `project`（工作区助手由身份强制）。`note.update` 允许把 project NULL 的想法改为某区（归属），已有归属的想法不允许跨区改。
- `tags.list` / `tag.*`：必须带 `project`。
- `mindmap.get/edit/preview/convert`：必须带 `project`；version 为该区版本；convert 目标固定本区。另提供 `mindmap.unassigned`（读）与归属动作（把某棵未归属树归到本区）。
- 页面：见 M12；`#note=<id>`、`#opening=<project>` 语义不变，只是落在 `/assistant.html?project=X`。
