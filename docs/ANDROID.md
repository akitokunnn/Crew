# Crew 安卓版：安装与配对

Crew 安卓版是电脑上 Crew 的手机遥控器：工作台、对话、待办、交付都在电脑上跑，手机通过同一个无线网连过去看和操作；另外多了语音对话和手机提醒。手机不需要联外网，也不需要账号。

## 1. 安装

1. 把 `Crew-debug.apk`（构建产物 `android/app/build/outputs/apk/debug/app-debug.apk`，约 280 MB，语音模型已打包在里面）传到手机。
2. 在手机上点开它。第一次会提示“允许安装未知应用”，按提示给文件管理器或浏览器打开这个权限，再点安装。
3. 这是调试版，没有上架，也没有正式签名；以后装新版本前，如果提示签名不一致，先卸载旧版。

## 2. 电脑上打开局域网访问

1. 电脑和手机连同一个无线网（公司访客网、开了“设备隔离”的网络可能互相看不到）。
2. 电脑 Crew：「设置 → 局域网访问」，选这台电脑的地址，打开访问。
3. 点「生成配对码」。会出现 8 位数字和二维码，5 分钟内有效，只能用一次。

## 3. 手机配对（三选一）

- **扫码**：打开 Crew 安卓版 →「扫码连接」→ 对准电脑上的二维码，直接进入工作台。
- **附近的电脑**：同一网络下，配对页会自动列出开着局域网访问的电脑；点它，再输入电脑上显示的 8 位码。
- **手动输入**：「找不到电脑？手动输入地址」，填电脑上显示的地址（如 `192.168.1.20:47812`）和 8 位码。

也可以用手机相机直接扫二维码，在手机浏览器里打开网页版（没有语音和提醒）。

配对成功后，电脑「已连接设备」里会出现“Crew 安卓版 · <手机型号>”。在电脑上点「强制下线」，手机会回到配对页。

## 4. 手机提醒

进入工作台时会问你要不要通知权限，选允许。之后电脑上出现**待拍板、要你亲手做的待办、任务交付、任务卡住**时，手机会弹通知，点开直达对应页面；电脑上“我已离开”开关关着也会提醒。

手机通知栏会常驻一条“已连接 <电脑名> · 随时接收提醒”。为了锁屏后也能及时收到：

- 在系统设置里把 Crew 的电池优化设为“不限制”/“无限制”；
- 部分品牌（小米、华为、OPPO、vivo 等）还要在“自启动”“后台运行”里允许 Crew。

电脑关机、睡眠或手机离开这个网络时收不到；重新连上后，期间的提醒会补上。

## 5. 语音

在**工作区助手**页面，输入框旁有「语音」按钮；手机工作区首页顶部也有。第一次会要麦克风权限。

- 直接说话，说完停一下（约 1 秒）就会发出去；助手的回复会念出来。
- 助手在念的时候你开口，它会立刻停下来听你说，并且知道你只听到了哪里。
- 「停止朗读」只是不念了；「停下助手」才会让助手停止手上的工作。
- **语音不能直接派活或改东西**：助手要动手时会弹出确认卡，必须在屏幕上点「确认执行」，说“确认”不算。
- 识别和朗读都在手机上完成，只把文字发给电脑。右上角“⋯”里可以切换“声音：系统 / 内置”。默认用手机自带的中文语音（念 PR、Codex 这类英文词更准）；手机没有可离线使用的中文语音时才用内置声音，内置声音会跳过英文词。

## 6. 常见问题

| 现象 | 怎么办 |
| --- | --- |
| “附近的电脑”里找不到 | 确认电脑开了局域网访问、两边在同一网络；Windows 防火墙要允许 Crew（Python）在专用网络通信；仍不行就扫码或手动输入。 |
| 配对码无效或已过期 | 在电脑上重新生成，5 分钟内输入。连续输错 5 次要等 5 分钟。 |
| 电脑换了 IP 后连不上 | 重连页会认出是同一台电脑的新地址，按提示重新配对一次（为安全起见，旧凭据不会自动发往新地址）。 |
| 打开显示“这台电脑已让你下线，请重新配对” | 电脑上点了强制下线，重新扫码或输码。 |
| 想换一台电脑 | 工作台顶部「换电脑」，可以切换或忘记已配对的电脑。 |

## 开发者：自己构建

```powershell
python android/scripts/fetch_assets.py
android\gradlew.bat -p android assembleDebug
```

需要 JDK 21 和 Android SDK 36（`ANDROID_HOME` 指向 SDK）。`fetch_assets.py` 按 `android/assets.lock.json` 下载并校验 sherpa-onnx AAR 和语音模型（约 220 MB，不进 git）。构建细节见 [android/README.md](../android/README.md)。
