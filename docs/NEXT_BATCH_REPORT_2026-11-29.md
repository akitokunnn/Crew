## 1. 一句话结论

**作战室会自己防停滞，成员按领头的选择开独立目录，能叫醒每位参战 leader，守则写进了后台；每位 leader 和工作区助手有了会成长的性格；安卓 App 能扫码配对、收通知、和工作区助手语音对话；上批尾巴全部收掉。**

1. **做完** · 作战室独立目录。领头在计划书里按成员选“独立目录”或共用目录。独立的成员在自己的 worktree 和分支里干活，收工后交 Git 管理员合并，合完自动清掉目录和分支；没合并的先存成备份引用，时间线给出恢复命令。共用的成员必须写清负责文件，互不重叠，界面标“未隔离”，收工时查越界。
2. **做完** · 叫醒参战 leader。被 @ 到、被派活的成员没有在跑的任务时，借自己的主会话收到消息并处理，同一条消息不会走两条路。
3. **做完** · 守则写进后台。分工写领头、筹备期发拍板卡、没存草稿就请顾问、“收到”“在等”这类空话帖，都由后台直接拒绝并说明原因；成员的进度帖不叫醒领头，只有完成、卡住、失败、提问才叫醒。
4. **做完** · 事件看门狗。替换了“空闲 10 分钟”提醒。房里每结束一个回合就判断一次，全员都没在干活又没完成目标，约 1 分钟后叫醒领头一次；叫醒后仍没进展，战况顶部和左栏作战室入口显示“等你关注”。
5. **做完** · 性格。引导和设置里能开关，每位 leader 和工作区助手各一份，可选 5 个起点或自己写，可见、可改、可重置、可定型；聊得多了后台自己整理成长，每份上限约 2 万 token。只影响直接和你说话的口吻，任务执行和作战室帖子不带。
6. **做完** · 安卓 App。扫电脑上的配对二维码直接进工作台，局域网内能自动发现电脑；手机在后台也能收到待拍板、待办、交付、卡住四类提醒；工作区助手页有语音，朗读中开口就停，语音里要派活或改东西会弹确认卡、只能点按钮确认。真机还没测。
7. **做完** · 尾巴。7 条审美细节、3 个红着的启动器测试、手机架构图编辑、Codex 侧栏露出的 leader 总对话、报告出处写法都已处理。
8. **做完** · 本批追加。提醒默认渠道改 Lark；“离开电脑”只认手动开关和 1 小时没有键鼠输入，锁屏不再算，回来连续用约 1 分钟自动退出离开，碰一下不算。

## 3. 现在能用什么

| 能力 | 你会看到什么 |
| --- | --- |
| 独立目录或共用目录 | 计划书分工行和“敲定，开打”确认框里写明谁独立、谁“未隔离”；独立目录的状态用“准备目录中 / 独立目录运行中 / 等合并 / 已清理 / 已备份”。 |
| 收工备份 | 没合并的改动存好后，时间线说清是谁的改动，点“复制恢复命令”就能找回。 |
| 越界检查 | 共用目录的人改了范围外的文件，战况“需要你关注”列出文件并叫醒领头；房间关了才发现的也会通知领头。 |
| 防停滞 | 房里全员停下约 1 分钟后领头被叫醒；仍没进展时左栏、目录、手机顶条都显示“等你关注”。 |
| 叫醒成员 | 在房里 @ 任何参战 leader 都能被叫醒回帖，回执显示“已送达：某某、某某”。 |
| 性格 | 设置「AI 性格」看每位的性格和容量；面板里选起点、编辑、定型、现在整理一次、看成长记录和恢复。 |
| 局域网配对 | 「设置 → 局域网访问」配对码旁有二维码，已连接设备里能看到“安卓 App”，能看到自动发现是否开着。 |
| 安卓 App | 扫码配对、后台提醒、工作区助手语音（字幕、朗读、打断、确认卡）。 |
| 手机架构图 | 手机上能选中分项、改名、移动、连线、回滚；没选中时划屏只移画布。 |
| Codex 侧栏 | Crew 退出或你停止后，leader 的 Codex 总对话自动从 Codex 桌面侧栏收起，再用时接着原对话。 |
| 离开模式 | 1 小时不碰电脑自动离开；回来连续用约 1 分钟自动退出，右下角提示“你回来了”。 |
