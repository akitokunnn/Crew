# V2 界面修复与浏览器证据

本轮在 `rebuild/v2`、基准 `a31ca95`（桌面 0.3.1）上实施；最终版本与提交由主控汇总。没有操作正式 HOME、正式 Crew 或真实 AI。

## 改动

- 总会话右上不再重复放“任务”资料按钮，任务内仍保留资料与交付入口。任务页显示明确的“返回任务清单”，状态文本不承担导航；总会话与任务草稿独立保留。
- 删除评论入口、菜单、表单、缓存与事件处理；历史数据不改。旧组信任 UI 的加载、初始化、挂载、源码与静态路径全部移除，任务决策由主控维护的任务模式承担。
- 关系图以“进行中的协作”及总数代替闪电，仅展示最多两条正在运行的临时协作及剩余数量，保留载体标识，标题按纯文本单行摘要显示；历史状态不明记录不再堆在关系卡上，仍可打开临时协作记录查看。成员连接线由连续主线承担，不依赖评论区高度。
- 修复待处理卡的大阴影被外层裁剪为矩形的问题，卡片使用清楚的边框。窄屏与同时展开关系图的布局均在浏览器检查。
- 任务不再常驻强调内部轮次，也不要求用户点“再开一轮”来继续修改。之前的报告显示为历史版本，保留真实版本与验收信息。
- 已完成任务的普通解释显示“回复中”，保留任务与验收状态；用户提出修改且 AI 明确登记变更后，在同一任务和执行内恢复工作显示。通过历史与现有 execution 接口更新，不增加另一套状态。
- 报告正文优先，附录改为可展开的“验证详情”：逐项通过/失败/未验证/模拟验证、原始证据引用、样例和未解决事项。去掉重复的交付叙述，原始报告数据和审计记录保留。
- 修复总会话被独立任务的工作状态误禁用压缩。目标压缩请求、历史和 SSE 均绑定 `goal_id`，只操作对应 execution。忙碌任务返回排队状态，完成后清除进度；未知 token 数显示“未知”。压缩完成通知按会话与目标分开去重。

## 实际验证

- `node --test plugin/tests/test_*.js`：**210 项通过，0 失败**。
- 在 `plugin` 目录、清除继承会话身份后执行 `python -m unittest test_report_documents test_context_http -q`：**17 项通过**。
- 主控协作者另验证关联后端 93 项通过；原生协作者验证 Codex 目标压缩只作用于对应原生会话，保留正在工作的总会话。这里的浏览器目标压缩使用假 CC 载体，二者覆盖同类入口。
- 新脚本 `plugin/tests/smoke_v2_ui_revision.cjs` 使用真实 Chrome、真实 HTTP 和 SQLite，仅替换 AI 载体。最终 **28 项行为检查全部通过，控制台错误 0**，保存 26 张逐步截图。截图快进有限动画，避免捕获半透明的进入状态；已人工核看关系图、任务页、追问页与四类弹窗。
- 已交付任务的解释与修改都从浏览器真实点击发送；解释期间核对任务版本、完成状态和验收记录不变，再用该执行的 AI 接口登记用户修改，验证同一执行切回工作显示且内部轮次不增加。
- `--old-ui` 将基准 `a31ca95` 的真实 UI 源码资源（含旧 chat 与旧信任资源）重新交给同一个浏览器执行，其他后台保持真实；最终到达 23 项检查，**其中 10 项确实失败，退出码 1**：旧任务/信任入口、评论入口、历史协作堆积、长文本、阴影裁剪、返回清单提示、旧菜单、压缩误禁用、解释仍显示工作等待与失效的取消引导。控制台错误为 0；失败证据独立保留，不覆盖成功结果。
- 已退役的评论和旧信任前端单元测试随入口移除，其他草稿、真实状态、验收计数与历史隔离检查保留；真实浏览器检查承担入口删除与导航行为验证。
- 最终复验曾暴露浏览器检查的等待竞争：发送结束与新 execution 的历史载入并非同一步，旧检查只等“不是正在发送”，会抢读临时“等模型回应”。对历史请求增加 400ms 延迟后稳定复现同一失败，截图随后已经显示“回复中”。修正测试为先核对新 execution 的 discussion history，再限时等待实际回复文字；没有修改生产代码或放宽断言。相同延迟下 24 项通过，正常最终复跑也 24 项通过；旧 UI 的回复文字检查仍失败。原失败、受控复现和修正结果分别保留在 `Temp/v2-ui-review/failure-before-history-settled/`、`history-readiness-repro/`、`history-readiness-fixed/`。
- 最后补查取消任务：删除的旧信任样式中前十行与窄屏规则实际供多个弹窗共用，原先 24 项未打开这些弹窗。新截图发现表单失去居中外壳，现将通用规则迁入 `style.css`，不恢复信任入口或资源。真实浏览器追加创建目标、创建组员、更换工具及取消确认的布局检查，关闭后可继续输入；取消还检查真实停止确认、只读提示与返回总会话。`--missing-dialog-css` 只移除这些共享样式，布局断言确实失败，反证保存在 `Temp/v2-ui-review/missing-dialog-css/`。

## 复跑

在仓库根目录 PowerShell 中运行（本机 Chrome 已安装，Playwright 使用 Codex 自带依赖）：

```powershell
$env:NODE_PATH='C:\Users\admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
node plugin/tests/smoke_v2_ui_revision.cjs
```

脚本自行清除 `CREW_SESSION_ID`、`CLAUDE_CODE_SESSION_ID`、`CREW_EXECUTION_ID`、`CREW_GOAL_ID`，建立临时 HOME，结束时关闭隔离服务并删除测试数据。需要本机 Chrome；其他机器可安装 Playwright 与 Chrome 后运行同一脚本。

反证命令：`node plugin/tests/smoke_v2_ui_revision.cjs --old-ui`，预期退出码为 1。

证据目录：工作树 `Temp/v2-ui-review/current/`（成功截图与 `evidence.json`）、`Temp/v2-ui-review/old-ui/`（失败截图与 `evidence.json`），前端单元测试日志 `Temp/v2-ui-review/js-all.log`。这些临时证据与数据库均不纳入源码提交。

本子任务没有验证正式实例升级和真实 AI 业务质量；最终打包与正式部署状态由主控另行核实。
