# 0.3.2：按本次反馈复测

先从应用或托盘菜单“退出 Crew”退出旧 V2，再打开 `Crew-V2-0.3.2-portable.exe`；关闭窗口的 × 只是收起。测试使用你自己的模型设置；本轮开发者真实验收使用原生发现的 `gpt-5.6-luna / low`。不用清库、删工作区或重建已有任务。

1. **助手回复。** 给全局助手发送“只回复：收到 032”。收到回复后输入草稿，切换工作区再回来。应保留同一助手、回复和草稿；没有回复时记录发送后状态与时间，不重复发送。
2. **任务导航。** 进入 leader 总会话，右上不再重复显示“任务”或“信任”。从任务清单进入任务后，应有明确的“返回任务清单”，任务状态不充当返回按钮。任务资料仍可在任务内打开。
3. **关系图与待处理。** 打开关系图和待处理卡。关系图不再有评论入口和不断增长的闪电条，当前协作只显示简短摘要，旧未知记录不堆在卡片上；连接线连续。待处理卡下不应出现大矩形阴影，窄窗口也不相互遮挡。
4. **压缩与继续对话。** 在已有历史的总会话中，发送“记住标记 COMPACT-032”，等回复结束再点压缩。应结束进度、可以继续输入。再问标记是什么。在任务对话也压缩一次，不能串到总会话或其他任务。忙时应明确排队；未取得原生用量时显示未知，不能用假数字宣称压缩效果。
5. **已交付任务内问答。** 在已交付并验收的任务内问“解释一下刚才的结论，不修改任何内容”。应只显示回复中，任务保持交付状态，需求、报告和验收不失效，也不自动开启第二轮。
6. **原任务小改。** 再说“在现有成果上修改这一点：【具体小改】，我同意开始”。AI 需明确更新原任务的修改内容后实施，继续同一个任务，保留旧报告与验收。界面不要求你办理轮次手续；只复核受影响的工作项。
7. **自主推进与权限。** 任务选择“自主推进”，不再额外设置组信任。它决定本任务工程取舍由谁拍板，实际工具权限仍看你的 AI 设置；AI 的实现偏好不能冒充你禁止改文件或禁止外部服务。
8. **报告。** 先看结果正文，必要时展开“验证详情”，检查实际通过、失败、未验证和原始证据。浏览器工具不可用时应保留原始错误并说明视觉未验证，不能编造已看过，也不应反复生成同一份报告。
9. **Codex 接回。** 仅在原生会话空闲时交给 Codex 桌面，确认桌面能看到同一对话；在桌面回复一条标记后再接回 Crew。若提示仍有写入者，结束原生执行并关闭持有该对话的客户端后重试，不能两边同时输入。本轮已在两个隔离原生客户端实测“占用时拒绝 → 原拥有者关闭 → 同 ID 接回并回复”，没有完成真实桌面 UI 往返验收；仅关闭一个桌面标签是否足以释放连接仍未知。

反馈只需：步骤编号、当时输入或点击的按钮、期望、实际现象、发生时间，以及完整报错或截图。尤其保留“助手已发出但未显示”“压缩一直等待”“接回时仍被占用”的现场；不要为绕过问题删除历史或原生锁文件。
