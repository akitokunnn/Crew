# Crew 网页交互设计

## 目标与视觉规范

Crew 是一个人在本机使用的协作工具。首屏先回答“现在需要我做什么”，随后回答“谁在管谁、各自在做什么”。进入具体会话后，以对话为主，相关进展与拍板放在旁边。

以 Linear 的信息密度和层级为主参考。背景 `#f7f8fa`，内容区白色，主操作 `#5e6ad2`；正文 14px、聊天正文 15px、页面标题 22px、次要信息 12px。间距使用 4 / 8 / 12 / 16 / 24px，图标使用 16px 线条 SVG。状态同时写文字：处理中、等你处理、本轮结束、未运行、已归档。没有进度事实时不制造完成百分比，不加动效。

主要按钮和正文要清楚可读；手机主要触控入口至少 44px。长路径、会话 ID、分支、运行地址放在详情中，列表先显示名字、任务或最新报告。

## 一个文件夹，一个网页

`crew web --open` 根据启动目录找到所属工作区，打开固定的 `/?project=名字`。已有后台服务时复用服务，不重复启动。一个后台服务可供多个工作区网页使用；每个网页始终只显示自己所属的工作区。

页面内没有项目切换器。裸网址是工作区入口，各工作区链接在新标签页打开。顶部和侧栏写清名字；浏览器标题采用 `(待处理数) 工作区 · Crew`。用量默认同一工作区，需要时明确切到“全机”。订阅额度始终是账户范围，另行标注。

## 三个入口

| 页面 | 首要内容 | 后续内容 |
| --- | --- | --- |
| 总览 | 需要你处理的事项，按阻塞、等回复、错误、失败任务、普通拍板排序 | leader → 成员 → Codex 的关系图、独立会话、资源和文件归属 |
| 会话 | 已加入 Crew 的会话，优先看任务和近况 | 可加入的已有会话、已归档、已移出 Crew、组建协作组和新建会话 |
| 用量 | Claude 5 小时 / 每周额度与 Codex 每周额度 | 当前工作区的 token、价格折算、会话与任务明细、导出 |

对话是“会话”下面的内容，不增加第四个导航。侧栏保留常用会话，旧的离线记录收起；`Ctrl+K` 可按名字或任务搜索，方向键选择，Enter 打开，Esc 关闭。

## 总览与关系图

- 待拍板显示提问人、问题、推荐、选项和阻塞状态。点击可以直接答复或进入对应会话。
- 原生 Claude 的提问或权限等待若只有状态记录，不伪造可在网页作答的选项，指向原会话处理。
- 一条问题已答、正在等下一轮接收时，不再为同一会话生成泛泛的“等你回复”。保存、已交给会话和实际已读分别表达。
- 错误与失败任务可标记为已处理，并可撤销；新一轮产生的新错误仍会出现。
- 关系图只连接有真实归属的会话和派活任务。没有 leader 的会话放在独立区域；没有派发者身份的 Codex 日志不能假接到某个会话。
- Codex 的开始与结束来自派活记录。只有日志、没有结束事实时显示未知，不能用最后一条 token 时间冒充完成时间。
- 点击会话进入该会话；点击有派发者的 Codex 任务进入对应会话并定位活动记录。

## 会话本身就能管理

每行、会话标题旁和详情里都有同一组操作：改名、调整分组、退组、归档、移出 Crew、恢复。leader 不作为普通组员挪组。

| 操作 | 实际后果 |
| --- | --- |
| 改名 | 修改协作名字；leader 同名组和成员归属同步更新 |
| 退组 | 保留会话，改为独立会话 |
| 归档 | 从当前协作列表收起，历史保留、只读 |
| 移出 Crew | 保留原会话、文件和历史；后续打卡不会自动加回 |
| 恢复 / 重新加入 | 恢复协作记录；不声称进程已经启动 |

这些操作只整理记录，不停止进程、关闭窗口或删除文件。可恢复的整理操作完成后提供“撤销”，不加二次确认。归档、移出和改名保留明确控制记录，原进程下一次启动或压缩不能把它们改回去。主动 `crew join` 视为重新加入。

空页面给出下一步：已有会话可加入，空工作区可新建会话或组建协作组；没有待处理事项时直接说清楚。

## 对话、活动与接续

对话保留流式回复、工具详情、草稿、阅读位置、失败提示和同 ID 恢复。忙碌时不能再次发送，草稿可以继续编辑。Enter 发送、Shift+Enter 换行，中文输入法选词不触发发送；向上读历史时不抢滚动。飞书来信显示“你 · 来自飞书”。

“活动记录”将报告、交接、设备借还、Codex 派活、拍板和会话整理合成一条时间线。原始调试事件放在次级展开区。收到的交接用实际投递身份保留，改名不会丢历史，旧名字被复用也不会串给新会话。

网页会话可直接继续聊；VS Code / 终端会话保留原运行端，网页展示状态和活动。转到 VS Code 仍分两步：先开准确目录，用户确认窗口就绪后再接续原会话 ID。忙碌、归属不明或接续失败时显示实际原因，不假称成功。

## 用量与离开状态

用量按工作目录匹配最长工作区根目录，包含未加入 Crew 的本地会话。全机范围是明确的独立切换，导出跟随范围。价格按 API 计价折算，只用于比较，不是订阅账单。

Claude 额度被动读取本机官方缓存和网页 CLI 的额度事件，显示采集时间、重置时间。窗口过期后不把旧百分比当作当前值；缺少数据写“未采集”，不写 0。Codex 额度同样标明账户快照。

顶部“我已离开”开关和桌面锁屏任一成立，才发送主动通知。飞书按约 30 秒合并事项；配置和接收故障有明确提示。卡片按钮未启用时不显示无效按钮，可以用文字按编号答复。实际配置及原生会话限制见 [FEISHU.md](FEISHU.md)。

## 适配与验收

桌面保留导航、对话和组内上下文；窄屏把导航与组内上下文放入抽屉。表格只在自身区域横向滚动，页面不横向溢出。对话框有标题、标签、Esc 和焦点归还；刷新状态不清空输入、不抢焦点、不收起用户已展开的工具。

验收使用临时白板、假进程和真实 HTTP/SSE，不向用户原会话发测试任务。不使用 computer use，不控制光标。视觉截图使用独立用户目录的无头 Edge，手机用设备模拟确保实际为 390px。当前改造前的问题清单与截图在 `Temp/review-20261022/`，隔离验收和改造后截图在 `Temp/usability-qa/`；正式页面在合入后另做只读截图。
